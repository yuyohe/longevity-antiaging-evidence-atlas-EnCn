# 纳入与排除标准 / Inclusion and Exclusion Criteria

## 优先纳入

- 人体 RCT、系统综述、meta-analysis。
- 大型前瞻性队列，尤其含死亡率、MACE、癌症、住院、功能衰退等终点。
- 与长寿、健康寿命、衰老生物学、临床预防、抗衰营销相关的关键论文。
- 动物寿命实验，但必须标注为 preclinical。
- 高影响力 geroscience 前沿研究，例如 senolytics、rapamycin、partial reprogramming、IL-11、Klotho、immune rejuvenation。
- 负面结果、撤稿、重复失败和反证研究。

## 暂缓纳入

- 只有细胞实验，且与 healthspan/longevity 关联弱。
- 商业白皮书、广告软文、未披露方法的数据。
- 无对照个案、社交媒体体验帖。
- 只有 biomarker 改善却声称“逆龄”的营销材料。
- 无法确认 DOI、PMID、PMCID、预印本编号或可信来源的内容。

## 排除原因必须记录

在 `data/sources.json` 或 `data/candidate_sources.csv` 中记录：

- `included`: true / false / needs_review
- `exclusion_reason`
- `last_checked`
