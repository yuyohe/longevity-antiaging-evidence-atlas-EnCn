## Update cadence

| Frequency | Work |
|---|---|
| Weekly | Run literature search and update candidate list |
| Monthly | Add 5–10 high-value paper cards |
| Quarterly | Update evidence ranking and public recommendations |
| Yearly | Reassess methodology and prune outdated claims |

## Search log

Every search should be logged in `data/query_log.csv` with:

- date
- source
- query
- result_count
- new_candidates
- included_count
- notes
