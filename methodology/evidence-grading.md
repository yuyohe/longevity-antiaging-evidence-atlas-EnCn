# 证据分级 / Evidence Grading

## Evidence level

| Level | Meaning | Typical source |
|---|---|---|
| A | Strong human clinical evidence | RCT/meta-analysis with meaningful endpoint |
| B | Strong observational or repeated human evidence | Large cohort, consistent human evidence |
| C | Limited human or surrogate evidence | Small RCT, short duration, biomarker endpoint |
| D | Animal lifespan/healthspan evidence | Mouse lifespan, preclinical intervention |
| E | Mechanism/cell/computational evidence | Pathway, gene expression, cell model |
| F | Unsupported or marketing-level evidence | Anecdote, uncontrolled claim, sales material |

## Endpoint class

| Class | Endpoint type | Examples |
|---|---|---|
| H1 | Hard endpoint | all-cause mortality, MACE, stroke, cancer incidence |
| H2 | Functional endpoint | VO2max, grip strength, frailty, cognition, AHI |
| H3 | Clinical risk marker | apoB, LDL-C, BP, HbA1c, waist circumference |
| H4 | Biomarker | NAD+, hsCRP, mitochondrial markers |
| H5 | Biological clock | DNA methylation age, proteomic clock |
| H6 | Mechanism/cell | pathway activation, gene expression |

## Recommendation class

| Class | Meaning |
|---|---|
| Strong Action | Reasonable lifestyle/risk-reduction action for general readers |
| Medical Action | Requires clinician evaluation or monitoring |
| Monitor | Frontier research; not a public recommendation |
| Do Not Recommend | Not supported or risk outweighs evidence |
| Insufficient Evidence | Not enough evidence or evidence conflicting |
