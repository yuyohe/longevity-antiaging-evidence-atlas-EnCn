# Evidence Grading / 证据分级

Evidence level ranks how much confidence a claim deserves. It is not a ranking of whether a topic is exciting.

证据等级衡量某个主张有多可信，而不是衡量主题是否“前沿”或“令人兴奋”。

## Evidence Level / 证据等级

| Level | Meaning | Typical source | 中文说明 |
|---|---|---|---|
| A | Strong human clinical evidence | RCT/meta-analysis with hard or functional endpoint | 强人体临床证据 |
| B | Strong observational or repeated human evidence | Large cohort, repeated human trials, Mendelian randomization | 强观察性或重复人体证据 |
| C | Limited human or surrogate evidence | Small RCT, short trial, validated risk marker | 有限人体或替代终点证据 |
| D | Animal lifespan/healthspan evidence | Mouse lifespan, ITP-style intervention, preclinical physiology | 动物寿命或健康寿命证据 |
| E | Mechanistic/cell/computational evidence | Cell model, pathway, omics, AI discovery, hypothesis generation | 机制、细胞或计算证据 |
| F | Unsupported or marketing-level evidence | Anecdote, uncontrolled claim, sales material | 不足或营销级证据 |

## Endpoint Class / 终点等级

| Class | Endpoint type | Examples | 中文说明 |
|---|---|---|---|
| H1 | Hard endpoint | all-cause mortality, MACE, stroke, cancer incidence | 硬终点 |
| H2 | Functional endpoint | VO2max, grip strength, frailty, cognition, AHI, falls | 功能终点 |
| H3 | Clinical risk marker | apoB, LDL-C, BP, HbA1c, waist circumference, eGFR | 临床风险指标 |
| H4 | Biomarker | NAD+, hsCRP, mitochondrial markers, inflammatory markers | 生物标志物 |
| H5 | Biological clock | DNA methylation age, proteomic clock, metabolomic clock | 生物年龄时钟 |
| H6 | Mechanistic endpoint | pathway activation, gene expression, cell senescence marker | 机制/细胞终点 |

## Recommendation Class / 推荐边界

| Class | Meaning | 中文说明 |
|---|---|---|
| Strong Action | Reasonable lifestyle or prevention action for general readers | 可作为一般生活方式/预防行动参考 |
| Medical Action | Requires clinician evaluation, prescription, or monitoring | 必须医生评估或监测 |
| Monitor | Frontier research; track but do not recommend publicly | 前沿观察，不作公众建议 |
| Do Not Recommend | Evidence weak, conflicting, or risk outweighs benefit | 不推荐 |
| Insufficient Evidence | Evidence too sparse or not yet interpretable | 证据不足 |

## Journal Impact Factor Rule / IF 使用规则

Journal Impact Factor, journal quartile, publisher reputation, and citation counts are authority signals only. They cannot upgrade a weak design into strong evidence.

影响因子、期刊分区、出版方声誉和引用量只是“权威性信号”，不能把弱研究设计升级成强证据。

Rules:

- IF contributes only to the authority component of the contribution score.
- IF should be recorded with year and source when available.
- For preprints, use preprint status and later publication status separately.
- For landmark older studies, low current IF or missing IF should not automatically penalize the paper.
- For review papers, high IF does not replace primary evidence quality.

规则：

- IF 只进入贡献度评分中的“权威性”子项。
- IF 必须尽量记录年份和来源。
- 预印本要单独记录预印本状态和后续正式发表状态。
- 经典老文献不能因为当前 IF 缺失或偏低而自动降级。
- 综述文章即使 IF 高，也不能替代原始研究质量。
