# 最常见 30 个补剂 / 30 Common Supplements

这页只讲普通人最常问的补剂。想看完整 100 个条目，再去看 [大众补剂速查](supplements.md)。

阅读顺序：一句话总结、常见误解、注意。不要把等级当购买建议。

| 补剂/成分 | 一句话总结 | 常见误解 | 注意 |
| --- | --- | --- | --- |
| 维生素 D | 更适合按缺乏风险和检测结果理解。 | 不等于健康人群人人补了就能延寿或美容逆龄。 | 过量有风险；慢病、肾脏问题或长期高量使用要问专业人员。 |
| 维生素 C | 可以看作常见营养素，不是抗衰核心答案。 | 不等于高剂量口服能延寿，也不能替代防晒。 | 高剂量可能带来胃肠不适或结石风险人群负担。 |
| Omega-3 / 鱼油 | 重点看心血管风险、饮食来源和个人情况。 | 不等于人人吃了就抗炎抗老。 | 抗凝药、手术前、出血风险或高量使用要谨慎。 |
| 胶原蛋白/胶原肽 | 主要看皮肤水分、弹性等外观指标。 | 不等于补了就能变年轻或延寿。 | 注意过敏、蛋白来源、肾脏基础问题和产品质量。 |
| 蛋白粉/必需氨基酸 | 对蛋白摄入不足或训练人群更有讨论价值。 | 不等于皮肤美容或延寿万能补剂。 | 肾病、肝病和特殊疾病人群要问营养或医疗专业人员。 |
| 肌酸 | 更常和力量训练、肌肉表现一起讨论。 | 不等于单独吃就抗衰或美容。 | 肾脏问题、多药使用或长期高量使用要谨慎。 |
| 钙/镁 | 要看饮食、骨骼、年龄和基础风险。 | 不等于无差别补充就能延寿或美容。 | 钙补充与结石、心血管风险讨论需要个体化；镁也要看肾功能。 |
| 锌 | 更适合按缺乏风险和特定场景理解。 | 不等于长期高量提升免疫或抗老。 | 长期过量可能影响铜代谢和胃肠耐受。 |
| 辅酶 Q10 | 可关注心血管、用药和疲劳相关研究，但证据不等于延寿。 | 不等于明确延寿或皮肤逆龄。 | 和抗凝药、慢病用药可能有关，长期使用先问专业人员。 |
| 褪黑素 | 更适合讨论睡眠节律，不是抗衰补剂。 | 不等于长期抗衰或美容。 | 嗜睡、药物相互作用、儿童、孕期和精神症状人群要谨慎。 |
| 益生菌 | 要看菌株、问题和人群，不能笼统说有效。 | 不等于所有人都适合，也不是通用抗衰方案。 | 免疫抑制、重症或特殊医疗状态要问医生。 |
| NMN | 属于热门候选方向，但结论不能跳太远。 | 不等于已经证实能让人延寿、逆龄或美容抗老。 | 长期安全性和适用人群仍需要更清楚的证据。 |
| NR | 和 NAD 相关，但仍不能直接推出延寿。 | 不等于已经证实外观逆龄或寿命延长。 | 长期净收益、特殊疾病人群和用药情况需要复核。 |
| NAD 前体 | 不同前体不能混为同一种效果。 | 不等于 NAD 提升就等于抗衰成功。 | 不同产品、剂型、人群和研究终点差别很大。 |
| 白藜芦醇 | 更多是候选研究和机制讨论。 | 不等于红酒或白藜芦醇能延寿。 | 药物相互作用和剂量差异要谨慎。 |
| 槲皮素 | 常被放在前沿抗衰讨论中。 | 不等于可以自己清除衰老细胞或抗衰。 | 可能有药物代谢相关相互作用。 |
| 姜黄素 | 可以讨论炎症、代谢等线索。 | 不等于抗癌、延寿或皮肤逆龄已经证实。 | 胆道疾病、抗凝药和胃肠耐受要注意。 |
| 绿茶儿茶素 | 可以看作多酚类研究方向。 | 不等于高浓缩提取物无风险或明确延寿。 | 高量提取物有肝毒性报告，需谨慎。 |
| 虾青素 | 更多是皮肤和抗氧化相关线索。 | 不等于能替代防晒、逆龄或延寿。 | 长期高量和特殊人群安全性仍需复核。 |
| 透明质酸 | 主要看皮肤水分和屏障。 | 不等于全身抗衰或延寿。 | 注射类属于医疗美容，不属于普通补剂结论。 |
| 神经酰胺 | 主要看皮肤干燥、屏障和经皮水分流失。 | 不等于吃了就全身变年轻。 | 皮肤病、过敏或复杂护肤方案要个体化判断。 |
| 烟酰胺 | 更适合放在皮肤屏障、色素和炎症讨论里。 | 不等于口服或外用都能延寿。 | 外用可能刺激；高剂量口服不应自行长期使用。 |
| 维生素 B12 | 重点看缺乏、贫血和神经相关风险。 | 不等于不缺也能提神、抗老或延寿。 | 素食、胃肠吸收问题、贫血或神经症状要做专业评估。 |
| 叶酸 | 主要看缺乏风险、孕前孕期和同型半胱氨酸相关场景。 | 不等于人人长期高量吃更健康。 | 备孕、孕期、贫血或 B12 状态不明时要按专业建议处理。 |
| 复合维生素 | 更适合饮食不足或特定人群，而不是健康人的万能保险。 | 不等于越全越好，也不等于能抵消差饮食。 | 重复叠加容易超量，尤其脂溶性维生素和矿物质。 |
| 维生素 E | 可以作为抗氧化相关候选方向。 | 不等于高剂量能预防衰老或心血管病。 | 高剂量和抗凝药、手术、出血风险有关。 |
| 维生素 A | 主要看缺乏、视力、免疫和皮肤角化问题。 | 不等于皮肤好就应该口服高剂量。 | 孕期、肝病、异维A酸或叠加补充时风险较高。 |
| 维生素 K2 | 更多放在骨骼和钙代谢讨论里。 | 不等于能清除血管钙化或单独防心血管病。 | 华法林等抗凝药人群不能自行补。 |
| 硒 | 主要看缺乏或甲状腺相关场景。 | 不等于补得越多免疫越强。 | 窄安全窗，长期过量可能有毒性。 |
| 碘 | 重点看缺乏和甲状腺健康。 | 不等于所有甲状腺问题都该补碘。 | 甲亢、甲减、结节、孕期或用药人群要专业评估。 |

## English Summary

This page covers 30 commonly asked supplements. It is not a recommendation list. The main use is to identify unsupported claims, safety boundaries, and when a topic should be handled by a qualified professional.
