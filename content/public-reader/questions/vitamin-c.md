# 维 C 精华改善皮肤纹理，有人体试验看过吗？

有。一项试验中，含维 C 的乳霜比不含维 C 的基底更能改善日晒后皮肤的表面纹理。

- **研究了谁：** 有日晒老化迹象的女性，研究部位是颈下和手臂，不是把各种维 C 精华往脸上比较。
- **测到了什么：** 研究持续半年，除了医生评分，还给皮肤纹理做印模，看到部分较深纹沟变浅。
- **有多大把握：** 能支持的是特定乳霜对这些部位的效果；不能从中推出某瓶精华能淡多少斑。
