# 证据权重方法说明

> 这页给维护者、内容创作者和深度读者看。普通读者可以先看 `content/public-reader/evidence-weight.md`。

本项目的核心不是“收集越多论文越好”，而是把候选文献分层：哪些更接近真实健康结局，哪些只是早期线索，哪些不能外推成个人方案。

## 权重判断

| 维度 | 加权方向 |
| --- | --- |
| 研究设计 | 系统综述、Meta 分析、RCT、大队列、孟德尔随机化优先 |
| 终点硬度 | 死亡、重大疾病、功能和生活质量高于单一指标 |
| 人体相关性 | 人体证据高于动物、细胞和机制推断 |
| 来源深度 | 全文、摘要、PMCID、方法清楚的文献高于题录级记录 |
| 文章影响力 | RCR、OpenAlex 引用数、DOI/PMID/PMCID 等文章级信号作为辅助，不替代 RoB/GRADE |
| 发表地/期刊 | S/A/B/C/D 分层加权；顶级综合/临床期刊和领域头部期刊加分，但不能单独决定等级 |
| 风险调整 | 商业宣传、利益冲突、样本小、长期安全性不清会降权 |

## 发表地/期刊怎么用

我们新增 `venue_tier` 和 `venue_score`：

| 层级 | 加分 | 含义 |
| --- | ---: | --- |
| S | 10 | 顶级综合医学、综合科学或主要临床专科期刊 |
| A | 7 | 衰老、营养、代谢、老年医学、皮肤或转化医学领域头部期刊 |
| B | 4 | 常见正规专业或综合期刊 |
| C | 1 | 有 DOI/PMID 或注册记录，但不是高权重发表地 |
| D | 0 | 未知、缺少发表地或预印本 |

这层权重只回答“发表在哪里”这个问题，不回答“研究本身是否可靠”。最终仍然看研究设计、终点、人群、偏倚风险和外推边界。

## A-E 分级

| 等级 | 含义 |
| --- | --- |
| A | 证据比较扎实，可优先理解，但不是个人处方 |
| B | 有不少支持，可以关注，但仍要看人群边界 |
| C | 有线索，不能当确定建议 |
| D | 很早期，主要是机制、动物、细胞、小样本或替代指标 |
| E | 信息不足，不应作为行动依据 |

## 公开表达边界

- 不把动物寿命实验说成人类延寿。
- 不把生物标志物改善说成真正逆龄。
- 不把皮肤外观改善说成全身抗衰。
- 不提供剂量、品牌、处方或购买建议。
- 药物、医美、高剂量补剂、慢病用药保留专业评估边界。
