## 我们在做什么

本项目不是“补剂推荐清单”或“抗衰处方”，而是一个中英双语、可审计、可持续更新的证据图谱。我们把证据分成三条并列路径：

1. 健康寿命证据图谱：死亡、疾病、功能、代谢、心血管、睡眠、运动、药物和 geroscience 机制。
2. 外观抗老与皮肤健康证据图谱：光老化、皱纹、色斑、弹性、水分、屏障、医美和皮肤安全性。
3. 补剂证据矩阵：同一种补剂分别评价健康寿命证据和皮肤美容证据。

核心原则：**终点必须分清楚**。皮肤水分改善不是延寿；动物寿命延长不是人体延寿；biomarker 改善不是“逆龄已证实”。

第一层是自动候选，不等于正式纳入。候选来源优先级如下：

## 证据等级如何看

对外显示使用 A/B/C/D，但内部先看终点类型。

| 终点代码 | 含义 | 示例 |
|---|---|---|
| L1 | 硬临床终点 | 死亡、心血管事件、骨折、癌症发生、疾病进展 |
| L2 | 健康寿命中间终点 | 血压、LDL-C/apoB、血糖、VO2max、肌力、认知、睡眠 |
| S1 | 皮肤临床/外观终点 | 皱纹、光老化评分、色斑、弹性、水分、TEWL、屏障 |
| S2 | 皮肤机制或仪器终点 | 胶原、MMP、角质层指标、细胞/动物皮肤模型 |
| M | 机制、动物、细胞或题录级线索 | 通路、动物寿命、体外抗氧化、仅元数据 |

证据等级草判：

| 等级 | 判断逻辑 |
|---|---|
| A | 系统综述、Meta 分析、大型 RCT、硬终点或强临床相关终点，人类相关性高 |
| B | 随机试验、较好队列、重复性较好的临床或功能终点 |
| C | 小样本、人群有限、替代指标、观察性证据或皮肤仪器指标 |
| D | 动物、机制、体外、题录级、商业宣传风险高或结果不稳定 |

## 贡献度如何测算

每篇研究或记录先按 100 分制打草分，后续人工复核可调整。

| 指标 | 权重 | 解释 |
|---|---:|---|
| 终点价值 | 20 | L1 > L2 > S1 > S2 > M；硬终点和人类功能终点权重更高 |
| 研究设计 | 20 | 系统综述、Meta、RCT、大队列优先 |
| 人类相关性 | 15 | 人体研究最高，动物和体外仅作机制线索 |
| 样本量与重复验证 | 10 | 样本量、中心数、重复研究、长期随访 |
| 效应与安全性 | 10 | 效应大小、临床意义、不良事件和风险收益 |
| 权威性信号 | 10 | PMID、DOI、ClinicalTrials ID、开放全文、指南或高可信机构来源 |
| 图谱覆盖价值 | 10 | 是否填补主题空白、是否代表关键干预或热门争议 |
| 双语解释价值 | 5 | 是否能清楚解释给中文和英文读者 |

当前不伪造或自动填充付费 IF。若 IF 不可获得，使用替代权威性信号：

- PMID / DOI / ClinicalTrials ID 是否存在。
- 是否系统综述、Meta 分析、RCT、大型队列或注册临床试验。
- 是否有开放全文、清晰方案或可信机构资料。
- 是否可被复核、复现、追踪。

## 补剂矩阵怎么读

补剂单独用双轴评分：

| 字段 | 含义 |
|---|---|
| `longevity_evidence_level` | 对健康寿命、疾病风险、功能或代谢终点的证据草判 |
| `skin_beauty_evidence_level` | 对皮肤美容、外观抗老、屏障或水分终点的证据草判 |
| `longevity_endpoint_class` | L1/L2/M 等健康寿命终点类型 |
| `skin_endpoint_class` | S1/S2/M 等皮肤终点类型 |
| `supported_claim_zh` | 当前最多能支持什么说法 |
| `unsupported_claim_zh` | 明确不能宣传什么 |
| `safety_notes_zh` | 安全性和适用人群边界 |
| `commercial_overclaim_risk` | 商业过度宣传风险 |

补剂矩阵不会给剂量、品牌或购买建议。它只回答：证据强不强、支持什么、不支持什么、风险在哪里。

## 安全边界

- 不提供医疗建议、诊断、处方、剂量或治疗方案。
- 药物、处方外用药、医美设备、激光/换肤、慢病补剂使用必须由专业人员评估。
- 动物和机制研究不能直接外推为人体延寿或美容效果。
- 皮肤指标改善不能写成“逆龄已证实”。
- 补剂不能替代饮食、运动、睡眠、疾病筛查或标准治疗。
