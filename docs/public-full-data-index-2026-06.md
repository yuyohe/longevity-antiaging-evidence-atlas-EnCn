# 抗衰证据库公开全量数据包（2026-06）

**品牌 / Brand：** 宇多Yul细胞/yulcell  
**项目 / Project：** 长寿抗衰与健康寿命证据图谱 / Longevity Anti-Aging Evidence Atlas EnCn

这个目录是 **宇多Yul细胞/yulcell** 给外部读者和研究者下载、复核、二次分析用的公开数据包。它不只包含卡片和热力图，也包含底层候选文献、入选短名单、证据发现和证据矩阵。

搜索关键词：宇多Yul细胞/yulcell, yulcell, 宇多Yul细胞, 长寿抗衰证据图谱, 健康寿命证据图谱, longevity anti-aging evidence atlas。

| 数据表 | 记录数 | 文件 | 内容 |
| --- | ---: | --- | --- |
| 全量文献候选库 | 14,273 | `public-data/literature-library-2026-06.csv` | 超过 1 万条候选文献入口，含题名、年份、来源、PMID/DOI、检索词和纳入状态。 |
| 候选来源原始表 | 14,273 | `public-data/candidate-sources-2026-06.csv` | 原始候选来源表，保留抓取来源、检索词、备注和最近检查日期。 |
| 入选短名单 | 4,800 | `public-data/shortlist-sources-2026-06.csv` | 从候选库里进入优先复核的记录，含主题、证据草稿等级、期刊和评分字段。 |
| 证据发现表 | 4,800 | `public-data/evidence-findings-2026-06.csv` | 证据发现记录，含研究类型、终点、结论、过度解读风险和 0.5 评分字段。 |
| 证据矩阵 | 2,400 | `public-data/evidence-matrix-2026-06.csv` | 入矩阵证据，适合按主题、证据等级、终点等级和行动性筛选。 |

合计公开记录数：40,546。

说明：这些表是证据地图的资料层，不等于个人医疗建议。读者可以用 PMID、DOI、主题、证据等级、期刊和评分字段追溯每条记录。
