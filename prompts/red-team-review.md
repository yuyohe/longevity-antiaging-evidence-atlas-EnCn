# Codex Prompt — Red Team Medical Review

Act as a skeptical medical editor.

Review all changed files in the current branch.

Flag:

1. Animal-to-human extrapolation.
2. Biomarker-to-lifespan extrapolation.
3. Missing medical-supervision warnings.
4. Missing citations or links.
5. Unsupported “proven”, “reverse aging”, “extends lifespan”, “cure”, or “best” language.
6. Missing limitations.
7. Inconsistent evidence grading.
8. Copyright risks.
9. Confusing Chinese translation.

Output:

- Critical issues
- Important issues
- Minor issues
- Suggested wording changes
